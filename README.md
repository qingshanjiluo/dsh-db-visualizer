# dsh-db-visualizer

> DeepSeek Harness 数据库 Schema 可视化插件

## 功能

- 🔌 **数据库连接**: 支持 PostgreSQL、MySQL、SQLite
- 📋 **Schema 浏览**: 列出所有表、行数、列信息
- 🔍 **表结构**: 显示列、类型、约束、索引、外键
- 📊 **SQL 查询**: 执行只读 SELECT 查询
- 🗺️ **ER 图**: 生成 Mermaid 语法的实体关系图
- 📈 **分析**: 表大小、索引使用、优化建议

## 工具

| 工具名 | 说明 |
|--------|------|
| `db_connect` | 连接数据库 |
| `db_schemas` | 列出所有表 |
| `db_describe` | 描述表结构 |
| `db_query` | 执行只读查询 |
| `db_er_diagram` | 生成 ER 图 |
| `db_analyze` | 数据库分析 |
